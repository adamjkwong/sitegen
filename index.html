SiteGen Storage

This repository serves as the automated storage and hosting engine for websites generated by SiteGen. All generated sites are organized and hosted within the generated-sites/ directory.

This project is part of my personal portfolio of technical experiments, exploring the intersection of Generative AI, local LLMs (Gemma/Ollama), and automated deployment pipelines.
